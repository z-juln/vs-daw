# 学习旋律模式设计

日期：2026-10-08

## 目标

在网格编辑器中练钢琴轨的**旋律线**（打字练习式）：只提示下一个音，弹对前进，弹错重试。

## 已确认决策

- 旋律提取：每个起音 step 只取**最高音**
- UI：网格底部居中悬浮面板 + 列/音高行高亮；**侧边栏「键盘录制」同步状态与开关**
- 学习状态挂在扩展全局、绑定工程 URI：**关闭该文件 tab 不退出学习模式**；再打开网格会恢复高亮
- 起点：当前播放头列及之后的第一个旋律起音
- 错音：照常出声 + 悬浮条抖/闪红 + 正确音高行闪一下，不前进
- 对音：出声 + 前进到下一旋律音并 seek 到该列
- 力度不参与判题；`=` / 休止跳过

## 架构

- `extractMelody(track, fromStep)` 纯函数（可单测）
- `extension.ts`：学习模式状态机（与 tab 无关）；`padHit` 在模式下先判题
- 网格 Webview：悬浮条 + 高亮；侧边栏 Recorder：按钮 + 下一个音/进度

## 非目标（v1）

- 不练整和弦 / 不练伴奏声部
- 不自动跟拍节拍器驱动前进
- 不改谱面内容
